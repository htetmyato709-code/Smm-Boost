Standard Parameters & Actions

1. လက်ကျန်ငွေ စစ်ဆေးခြင်း (Balance)

2. ဝန်ဆောင်မှုများ ကြည့်ရှုခြင်း (Services List)

key: သင်၏ API Key

action: add

link: Target Link

4. အော်ဒါအခြေအနေ စစ်ဆေးခြင်း (Status)

action: status
